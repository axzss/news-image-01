A newspaper front page summing up Friday, 13 November 2026: the Nvidia chief resigns as shares plunge 16%, Microsoft 365 goes dark in a worldwide outage, a tanker hits a mine in the Strait of Hormuz as the US pulls back from Iran talks, Europe wins a seat at the Ukraine talks, and a strike hits Khan Younis hospital.

The image is rendered deterministically with Pillow from `build_image.py`, which lays out the masthead, hero image, and four stories on a 1024x1024 front page. `main.py` copies the finished image to the output path.

## Run it

```sh
python3 main.py
```
